Deskrpisi Projek
# PPAW Week 6 - Product Store

Project individu untuk tugas PPAW Week 6:
JavaScript DOM, Event Handling, dan Fetch API.

## Fitur

1. Fetch API
   - Mengambil data dari https://dummyjson.com/products
   - Mengolah response JSON
   - Menampilkan nama, kategori, gambar, dan harga produk
   - Menangani loading dan error

2. Form DOM & Event Handling
   - Validasi input pengguna
   - Event listener submit dan input
   - Feedback dinamis pada halaman
   - Reset form setelah berhasil diproses

## Teknologi

- HTML5
- CSS3
- JavaScript
- Fetch API
- DummyJSON API

## Cara Menjalankan

1. Clone atau download repository.
2. Buka folder project di VS Code.
3. Jalankan index.html menggunakan ekstensi Live Server.
4. Pastikan koneksi internet tersedia.
5. Uji fitur daftar produk dan form kontak.

## API

https://dummyjson.com/products
